RESPONSIVE STUDENT PORTFOLIO WEBSITE

FILES
- index.html: website content
- style.css: responsive styling
- script.js: mobile navigation and contact form demo

RUN IN VS CODE
1. Extract this ZIP.
2. Open VS Code.
3. Choose File > Open Folder and select responsive_student_portfolio.
4. Open index.html.
5. Install the "Live Server" extension if needed.
6. Right-click index.html and choose "Open with Live Server".

No build tools or npm packages are required. The contact form is a demo; to prepare an email, replace your-email@example.com in script.js with your own email address.
